# JOIN en MySQL

Proyecto educativo de Formación SOC para practicar `INNER JOIN`, `LEFT JOIN` y `RIGHT JOIN` con la base de datos Universidad. Los ejercicios resueltos relacionan carreras, materias, estudiantes y profesores.

## Cómo practicar

1. Abre [index.html](index.html) en el navegador y entra en [los ejercicios de Universidad](universidad.html).
2. Descarga [universidad.sql](sql/universidad.sql). Usa las sentencias de creación de tablas e inserción de datos para preparar la base de datos en MySQL.
3. Selecciona el filtro **JOIN · Consultas** para ver los ejercicios de consultas. Puedes copiar cada solución y ejecutarla en MySQL.

## Archivos del proyecto

- [index.html](index.html) presenta el proyecto y enlaza con el ejemplo.
- [universidad.html](universidad.html) muestra los ejercicios, sus filtros y el índice.
- [universidad.sql](sql/universidad.sql) contiene la preparación de la base de datos y las consultas.
- [universidad.js](assets/js/data/universidad.js) contiene los enunciados y las soluciones que se muestran en la web.
- [app.js](assets/js/app.js) genera el índice, aplica los filtros y permite copiar el SQL.

La web es estática y se puede publicar desde la raíz del repositorio con GitHub Pages.
